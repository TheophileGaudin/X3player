# X3player

`X3player` is a standalone local video player for the RayNeo X3 Pro AR glasses.

## Status

This is an early public release intended to make local video playback easier for X3 users.

## Usage

Copy videos to the glasses storage, ideally into `Movies` or `Downloads`, then launch `X3player`.

## Subtitle

Due to OS limitations, only `.srt` subtitles are compatible with the app. If your subtitle file format is different, please use one of the numerous free online subtitle converters available such as [gotranscript](https://gotranscript.com/subtitle-converter).
